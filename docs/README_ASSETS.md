# README assets

`moops-loop.drawio` is the editable diagrams.net source for the README diagram.
`moops-loop.svg` is its repository-friendly export.

The diagram uses two official product assets:

- `assets/nodejs-icon.svg` comes from the
  [Node.js branding page](https://nodejs.org/en/about/branding/).
- `assets/xcode-icon.png` comes from the Xcode 26.6 application bundle at
  `/Applications/Xcode.app/Contents/Resources/Xcode.icns`. It was resized to
  96 × 96 pixels.

The Draw.io source embeds both assets. The SVG reads the checked-in copies.
No logo was redrawn or generated.

To update it:

1. Open `moops-loop.drawio` in diagrams.net.
2. Keep the page at 2000 × 6000.
3. Export as SVG with the off-white page background and embedded font disabled.
4. Preserve the SVG title and description for accessibility.
