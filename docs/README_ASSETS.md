# README assets

`moops-loop.drawio` is the editable diagrams.net source for the README diagram.
`moops-loop.svg` is its repository-friendly export.

The diagram uses only vector shapes, system fonts, and colors defined in the
source. It has no external assets or generated imagery.

To update it:

1. Open `moops-loop.drawio` in diagrams.net.
2. Keep the page at 1240 × 760.
3. Export as SVG with a transparent background and embedded font disabled.
4. Preserve the SVG title and description for accessibility.
